<h1>🎨 CSS Flexbox Layout Practices</h1>

<p>
  Repositori ini berisi dokumentasi serta implementasi latihan pembuatan berbagai tata letak (<i>layout</i>) antarmuka web modern berbasis <b>HTML5 Semantik</b> dan <b>CSS Flexbox</b>. Proyek ini dirancang untuk melatih pemahaman mendalam terkait struktur dokumen web yang bersih, aksesibel, dan responsif.
</p>

<h2>🛠️ Teknologi & Fitur Utama</h2>
<ul>
  <li><b>HTML5 Semantik:</b> Menggunakan tag semantik seperti <code>&lt;header&gt;</code>, <code>&lt;nav&gt;</code>, <code>&lt;main&gt;</code>, <code>&lt;section&gt;</code>, <code>&lt;aside&gt;</code>, dan <code>&lt;footer&gt;</code>.</li>
  <li><b>CSS3 Flexbox:</b> Memaksimalkan properti <code>display: flex</code>, <code>flex-direction</code>, <code>justify-content</code>, <code>align-items</code>, dan <code>flex-wrap</code>.</li>
  <li><b>Clean & Modular Code:</b> Pemisahan file HTML dan CSS secara terstruktur untuk tiap modul.</li>
</ul>
